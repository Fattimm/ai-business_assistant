# AI Business Assistant — Atelier Prompt Engineering

Atelier pratique de prompt engineering réalisé dans le cadre de ma formation.

## Contenu

- `notebook.ipynb` : réalisation complète de l'atelier (9 parties), prompts testés et résultats commentés.
- `data/` : dataset de capteurs utilisé pour la Partie 6 (Machine Learning).
- `images/` : captures d'écran des réponses obtenues via l'interface web.

## Outils utilisés

- Interface web (ChatGPT) pour les Parties 1 à 5.
- API Google Gemini pour les Parties 6 à 9.

## Installation

```bash
pip install -r requirements.txt
```

`requirements.txt` :
pandas
python-dotenv
google-generativeai
ipykernel


## Structure de l'atelier

1. Anatomie d'un prompt
2. Comparaison des techniques de prompting
3. Prompt Engineering et raisonnement
4. Sorties structurées
5. Prompts pour applications métier
6. Prompt Engineering pour le Machine Learning
7. Prompt Engineering et RAG
8. Évaluation et optimisation des prompts
9. Bonus — Mini-pipeline bout-en-bout
